항공권 예약할 때 쓰는 코드

항공권을 결제할 때는 LINKPRICE 계열 코드를 먼저 확인해보세요. LINKPRICE6000 코드는 3% 할인이 적용되고, 할인 한도는 최대 10만원입니다. 결제 금액이 큰 국제선 항공권일수록 체감되는 조건입니다.

기본 코드인 LINKPRICE도 최대 10만원까지 할인이 적용됩니다. 해외 항공사 노선을 예약할 때는 GLOBAL 코드도 함께 확인해보시길 바랍니다. GLOBAL 코드 역시 최대 10만원까지 할인 한도가 걸려 있어서, 특가로 나온 항공권에 적용하면 실제로 부담하는 금액을 줄일 수 있습니다.

숙소 예약은 체크인 날짜가 가까워질수록 가격이 바뀌는 경우가 많아서, 코드를 적용한 최종 결제 금액을 캡처해두면 나중에 비교하기 편합니다.

결제 금액이 최소 기준에 못 미치거나, 이미 특가로 할인된 상품이라 중복 할인이 막혀 있는 경우도 있습니다. 이럴 때는 코드를 하나씩 바꿔가며 시도해보고, 그래도 안 되면 지금 올라와 있는 코드가 바뀌었을 가능성도 있으니 메인 페이지에서 최신 코드를 다시 확인해보시길 바랍니다.
